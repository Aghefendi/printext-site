# printext-site

Public privacy policy and support pages for the iOS app **Printext: Text Message Export**, served with GitHub Pages:

- https://aghefendi.github.io/printext-site/
- https://aghefendi.github.io/printext-site/privacy.html
- https://aghefendi.github.io/printext-site/support.html

The pages are plain static HTML with inline CSS: no JavaScript, no analytics, no external fonts or other third-party
resources.

`privacy.html` and `support.html` are generated from `docs/site/privacy.md` and `docs/site/support.md` in the private
app repository. Change the Markdown there first, then regenerate these pages; do not edit the wording here by hand.
